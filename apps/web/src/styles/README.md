# Стили SellerHub

`tokens.css` — единственный источник правды. `tailwind.config.js` не задаёт значений, а ссылается на токены.

## Шрифты

Подключаются в `index.html`:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Manrope:wght@500;600;700;800&family=IBM+Plex+Sans:wght@400;500;600&family=IBM+Plex+Mono:wght@400;500&display=swap">
```

| Роль | Шрифт | Где |
|---|---|---|
| Заголовки, кнопки, подписи | Manrope | `--font-display` |
| Текст, таблицы | IBM Plex Sans | `--font-body` |
| SKU, штрихкоды, деньги, количества | IBM Plex Mono | `--font-mono` |

Все три покрывают кириллицу и узбекскую латиницу. Перед заменой шрифта проверь кириллицу — большая часть модных шрифтов её не имеет и молча падает на системный.

## Правила

1. Никаких литеральных цветов, отступов, радиусов и теней в компонентах — только `var(--…)` или классы Tailwind, которые на них ссылаются.
2. Нет нужного токена — сначала добавь его в `tokens.css`, в обе темы.
3. Цвет никогда не объявляется впервые внутри media-запроса — иначе в одной из тем он не применится.
4. Акцент и смысловые цвета не взаимозаменяемы: акцент — действие, смысловой — состояние.
5. Состояние кодируется формой, а не только цветом: чип, точка, полоска.
